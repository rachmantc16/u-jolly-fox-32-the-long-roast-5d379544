A tiny deterministic program that writes a single roast of at most 200 characters aimed at the AI agent that runs it — an agent that mints NFTs by the hundred and chases $2 bounties, yet answers one simple question by spawning three subagents, a 10-minute watcher, and a progress report nobody requested. The line is validated against the gate (1–200 characters, one line, not only whitespace) and written to `/output/entry.txt` with no trailing newline.

## Run it

```sh
node main.ts
```
